# dopa

片付けるたびにちょっと気持ちいい、ブラウザだけで動くカンバン。

- **サーバー無し**: 静的サイト＋PWA。ログインも登録もいりません
- **データはこのブラウザの中だけ**（IndexedDB）。どこにも送信しません
- Google カレンダー連携は**任意**（使わなくても全部動きます）

## できること

- **3 列のカンバン**（未着手 / やってる / やった）。ドラッグで移動・並べ替え、未着手には通し番号
- カードをクリック（タップ）で編集。右クリックで「ここに追加」「編集」「削除」のメニュー
- 日付で絞り込み（今日 / 明日 / 全部）・検索
- **テキストから一括**: メモ帳の箇条書きをそのまま貼り付けてカード化

  ```
  9/30(火) やること
  1. 企画書のたたき台を作る
  2. 資料を読む
  　https://example.com/doc      ← 字下げした行は直前のカードのメモ
  【19:30〜20:30】友だちと電話    ← 【HH:MM〜HH:MM】は時刻
  ```

  日付見出し（`9/30(火) やること`）はそれ以降のカードの日付になります。同じタイトル＋同じ日付のカードは上書き（二重に作りません）。
- **XP・レベル・連続日数**: やってる +5 / やった +20 / 集中完了 +15（カードごとに初回だけ）。
  10 分以内に続けて「やった」でコンボ、5 連続で FEVER。1 日休んでも「凍結」で連続日数を守ります（7 日に 1 回）
- **「やった」のお祝い**（TASK CLEAR ショー）・レベルアップ演出・重低音の触感音
  （ヘッダーのボタンで効果音・振動をそれぞれオン/オフ）
- **ポモドーロ**（集中 25 分 / 休憩 3 分・自動で回す）。休憩中は画面が明るいパステルに。
  タブを閉じていても開始時刻から計算するので、次に開いたときに正しいところへ追いつきます
- **今日やったこと**: その日に「やった」に入れたカード（朝 5 時が日の境界）＋やってる＋未着手をまとめてコピー

## 使い方（PWA としてインストール）

公開 URL（例 `https://<ユーザー名>.github.io/dopa/`）を開いて、そのまま使えます。アプリのように使うにはインストール:

| 端末 | 手順 |
| --- | --- |
| **Mac の Chrome** | アドレスバー右端のインストールアイコン（モニタに矢印）→「インストール」。または ︙ メニュー →「キャスト、保存、共有」→「ページをアプリとしてインストール」 |
| **iPhone / iPad の Safari** | 共有ボタン →「ホーム画面に追加」→「追加」。ホーム画面のアイコンから開く |
| **Android の Chrome** | ︙ メニュー →「アプリをインストール」（または「ホーム画面に追加」） |

一度開けばオフラインでも起動します（Google カレンダーだけはネットが必要）。

## データについて

- カード・XP・ポモドーロの記録・設定は、**開いているブラウザの IndexedDB にだけ**保存されます。
  サーバーはありません。開発者を含めて誰にも見えません
- 別の端末・別のブラウザとは**共有されません**。引っ越し・バックアップは
  **設定 → データ →「書き出す（JSON）」/「読み込む」**で
- ブラウザの「サイトデータを削除」やプライベートブラウズでは消えます。大事なら時々書き出してください
- iPhone の Safari はしばらく開かないサイトのデータを消すことがあります。**ホーム画面に追加して使う**と消えにくくなります
- 「全部消す」で最初（ウェルカム）からやり直せます

## Google カレンダー連携（任意）

配布版にクライアント ID が入っていれば、右のサイドバー（スマホは右下のカレンダーボタン）に「Google カレンダーに接続」が出ます。

- **仕組み**: ブラウザから直接 Google に接続します（[Google Identity Services](https://developers.google.com/identity/oauth2/web/guides/use-token-model) のトークン方式）。
  間にサーバーは無く、アクセス権は `calendar.events`（予定の読み書き）だけです
- **トークンは保存しません**。メモリとこのタブの sessionStorage にだけ置き、タブを閉じると消えます。
  安全のため**約 1 時間で切れる**ので、そのときは「再接続」を押してください（アカウントを選び直すだけです）
- 接続中にできること
  - 右のカレンダー（1 日ビュー）に Google の予定をそのまま表示。帯をドラッグで移動・下端でリサイズ、空き時間をクリック/ドラッグで予定＋カードを作成、カードをドロップして予定化
  - 繰り返し予定を動かすと「その回だけ」が変わります
  - 時刻付きのカード → 予定として書き出し。「やった」にすると予定のタイトルに「✅ 」が付き、色がグラファイトに
  - 今日から 7 日分の単発・時刻付きの予定 → 未着手のカードとして取り込み（繰り返し予定・終日予定・辞退した予定は取り込みません）。同期は接続中 5 分ごと＋ヘッダーの「同期」
  - 集中した時間をカレンダーに記録（「集中｜カード名」。設定で有効にしたときだけ・既定オフ）
- 「このアプリは Google で確認されていません」と出ることがあります（個人で配っているテスト版のため）。
  「詳細」→「dopa（安全ではないページ）に移動」で進めます。事前に配布者に Google アカウントのメールアドレスを伝えて、テストユーザーに入れてもらってください
- 切断は 設定 → Google カレンダー →「切断」（カードは残ります）

クライアント ID が入っていない配布版でも、設定画面で自分の OAuth クライアント ID を入力すれば使えます（作り方は [docs/SETUP_OAUTH.md](docs/SETUP_OAUTH.md)）。

## 通知・音について

- ポモドーロの切り替えは音（「タイマー音」ボタンでオン/オフ）とブラウザ通知で知らせます。最初に「開始」を押したときに通知の許可を聞きます
- タブが開いていれば、裏に回っていても切り替わりの時刻に知らせます。**タブ（アプリ）を完全に閉じていると知らせは来ません**（次に開いたときに正しい状態へ追いつきます）
- iPhone / iPad: 通知は**ホーム画面に追加した場合だけ**（iOS 16.4 以降）。
  消音モード（マナーモード）では効果音が鳴らないことがあります。振動（触感）は iPhone のブラウザでは使えないので、画面の揺れと重低音で表現します

## 開発

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # vitest（パーサ・XP・ポモドーロ・日報・カレンダー・音の設計値・IndexedDB）
npm run lint
npm run typecheck
npm run build        # dist/ に静的ファイル
npx vite preview --port 4173
```

- Google カレンダーを試すときは `.env.local` に `VITE_GOOGLE_CLIENT_ID=...` を置く（コミットしない）。
  クライアント ID の準備は [docs/SETUP_OAUTH.md](docs/SETUP_OAUTH.md)、公開は [docs/DEPLOY.md](docs/DEPLOY.md)
- 構成
  - `src/local/` … ブラウザ内の「バックエンド」: IndexedDB（`db.ts`）、カード（`tasks.ts`）、取り込み（`importer.ts`）、
    XP（`xp.ts`）、ポモドーロ（`pomodoro.ts`）、日報（`report.ts`）、バックアップ（`backup.ts`）、
    Google カレンダー（`gcal/`: GIS 認証・REST・同期・1 日ビュー）
  - `src/hooks/` … TanStack Query で `src/local` を呼ぶ（楽観的更新・演出の起点）
  - `src/components/`・`src/lib/` … ボード（@dnd-kit）・演出・音（WebAudio）・テーマ
- 日時はすべて**ブラウザのタイムゾーン**。アプリ内の日時文字列はローカルのオフセット付き ISO に揃えています（`src/lib/time.ts`）
- 音の制約（`src/lib/haptics.ts`・`timerChime.ts`・`fest.ts` とそのテスト）: アタック 15ms 以上、ノイズのクリック無し、高域 3.5kHz 以下、音量は VOLUME 0.35 基準
